# Eğitim Verileri (01.01.2025 – 31.12.2025)

Bu klasöre EPİAŞ Şeffaflık Platformu'ndan indirilen 2025 CSV'lerini koyun:

- `GZT_2025.csv` — Gerçek Zamanlı Tüketim (hedef değişken)
- `PTF_2025.csv` — Piyasa Takas Fiyatı (Gün Öncesi Piyasası)
- `SMF_2025.csv` — Sistem Marjinal Fiyatı (Dengeleme Güç Piyasası)
- `SY_2025.csv`  — Sistem Yönü (Dengeleme Güç Piyasası)

Notlar:
- CSV'ler platformdan indiği haliyle `;` ayraçlı kalmalı; Excel'de açıp yeniden kaydetmeyin.
- Kolon adlarını değiştirmeyin.
- Farklı dosya adları kullandıysanız sorun değil — Komut 2'de Claude Code yolları uyarlayacaktır.
